## Global constraints

- **No visual redesigns.** Every animation change preserves the design's look for capable devices; low-tier devices get reduced/paused effects via the existing token system (`--ta-*`, `html[data-tier]`), `prefers-reduced-motion`, and `Save-Data`. No capability detection beyond OS-level signals (CLAUDE.md rule 4).
- **No behavior changes to conversion tracking or payments.**
- **Customer-facing copy rules (CLAUDE.md §11)** apply to any touched string.
- Client-data changes must not break freshness guarantees the business relies on: promo/multiplier flips must reach guests within ≤120 s on promo surfaces; draw countdowns tick client-side and never need polling.
- Norm rule 10: no new `/api/admin/**` reads planned; if a task adds any admin read, flag it.
- Each task: type-check + eslint on touched files + named `test:*` suites + doc updates in the same task. New test files get `package.json` entries + `docs/infrastructure/testing.md` registry lines.
